      1. Le backend .NET démarre
         ↓
      2. Le code détecte que l'OCR n'est pas démarré
         ↓
      3. Le code démarre automatiquement l'OCR
         ↓
      4. Le code attend que l'OCR soit prêt
         ↓
      5. Logs affichent : [INFO] OCR service prêt
         ↓
      6. Le backend continue normalement
         ↓
      7. L'OCR tourne en arrière-plan
         ↓
      8. Quand vous arrêtez le backend (Ctrl+C)
         → L'OCR s'arrête automatiquement aussi

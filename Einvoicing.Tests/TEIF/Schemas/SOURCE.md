# Schéma TEIF 1.8.8

`teif-1.8.8-withoutSig.xsd` : schéma XML de la facture électronique tunisienne (TEIF 1.8.8, Tunisie TradeNet),
version XSD 1.0 sans signature, utilisée par les tests pour valider le XML généré par `TeifService`.

Source : https://github.com/ayoubgaouet/tn-einvoice-validator (resources/xsd/teif-1.8.8-withoutSig.xsd),
qui reprend le XSD officiel publié par Tunisie TradeNet. Téléchargé le 17/11/2026.
